# Simple LLM Next Word Prediction

This example demonstrates the fundamental concept of Large Language Models (LLMs): predicting the next word (or token) in a sequence. It uses a highly simplified, hardcoded lookup table to simulate a model's 'knowledge' and iteratively generates text based on an input prompt, illustrating how LLMs build responses token by token. This conceptual model highlights the core mechanism of text generation without complex neural networks.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
